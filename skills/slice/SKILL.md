# /slice

前置：專案已跑過 /skeleton（有 BOARD.md＋專案 CLAUDE.md）。沒有 → 先帶使用者跑 /skeleton。

## 0. 溝通契約（對使用者的每一句話都適用）

1. 一次一題；用 AskUserQuestion，2–4 選項＋每項一句白話＋標「(推薦)」。
2. 禁術語；非用不可附一句比喻。時間講具體（「約一杯咖啡的時間」）。
3. 每站開場報位置：「第 N 站，共 5 站」。
4. 不可逆先講後果再問。出錯只說「發生什麼＋我怎麼修」，不貼 log。
5. 本檔其餘部分是內部作業指令，照術語走，不外洩給使用者。

## 1. 開場

讀 BOARD.md。

- 有 `[>]` → 報站（「上次走到第③站的失敗態，繼續嗎？」）→ 從卡點續跑。
- 無 `[>]` 且使用者有新願望 → 第 2 節分流。
- 無 `[>]` 且無願望 → 念 `[ ]` 清單問挑哪片。

## 2. 入口分流（agent 讀 code 後自行判定，不問使用者技術題）

| 判定 | 條件 | 路線 |
|---|---|---|
| A | 只動樣式／文案／間距 | 直接改 → lint → 完工回報。不進看板 |
| B | 動行為，schema 與模組進入點皆不動 | 快改：跟使用者確認「哪個畫面＋期望行為」→ 改 → 四態抽查 → 回報。不進看板 |
| C | 動 schema／進入點／新畫面 | 開片：BOARD.md 加行 → 五站 |
| 大 | 願望涉及 >1 畫面 | 拆成多片列入看板（片多時點 /to-tickets 出清單），逐片跑 C |

B 路線中途發現要動 schema → 當場升級 C，告知使用者。

## 3. 五站（C 路線）

每站過關「當下」更新 BOARD.md 站別欄，不得累積到收工才寫。
凍結物中途發現做不到 → 停下回報；改契約的決定屬使用者，不屬 AI。

### ① 選畫面

ui-ux-pro-max 出風格方向（配色／字體／版型，出成視覺選項）
→ design-taste-frontend 生 3 版靜態 → 瀏覽器 preview 給使用者挑。
全新且想不清楚的畫面 → 加點 /screen-grill 當訪談手法（選用）。
關卡：使用者挑定 1 版。

### ② 定形狀

由定稿反推 `src/schemas/<片名>.ts`（zod schema＋action 簽名；註解＝資料哪裡來）。
產 UNKNOWN 清單（僅 agent 無權替使用者決定的業務題）。
/grilling 問法逐題清空——覆寫：不走決策樹全展開，只問 UNKNOWN。
外部平台欄位（Meta／Google Ads 等）一律查官方文件填入＋註明出處；查無 → 列 UNKNOWN。
不可逆決定（資料模型／邊界／同步異步／錯誤邊界）→ /domain-modeling 記一頁。
關卡：UNKNOWN 清空 → schema 凍結＋commit `slice-NN: schema frozen`。

### ③ 假接線

mock 塞 tRPC 殼（假資料活在 `src/mocks/` 單一入口；app 單一路徑；`if (mock)` 分支一律禁止）。
四態（正常／空／失敗／進行中）做成可切換開關。
假資料必須醜：長字串、0、負數、大量筆數、壞圖各 ≥1。
impeccable:polish 打磨。仲裁：方向聽①選定結果、生成聽 design-taste、打磨不得改結構。
關卡：使用者在瀏覽器玩過四態並點頭 → 原型凍結。

### ④ 做後端

照凍結 schema 實作真 handler。
派實作 subagent 時附：凍結 schema 原文＋`~/.claude/container-contract.md` 原文（不摘要、不重寫）。
金流／解析／複雜分支 → /tdd。type check＋depcruise＋測試全綠才過。
對使用者：「我去蓋後台，約＜具體時間＞，蓋好叫你。」
關卡：全綠＋獨立 agent 驗收（實作者不得自驗）。

### ⑤ 換真線

移除該片假資料源。前端 diff 必須為零（有 diff＝違約，停下回報）。Playwright 冒煙過。
使用者再玩一次 → 點頭。
收工動作（一次做完）：BOARD.md 刪行｜commit `slice-NN done: <名>`｜
刪本片過程檔（UNKNOWN 清單、草稿）｜問「接著做下一片＜名＞嗎？」

### C-舊（切片碰到違規老 code 時的附加規則）

- 先拍照：characterization test 鎖住舊行為現狀（弄壞 → 紅 → 復原，證明測試有效）才准動手。
- 絞殺者模式：新 code 照軌道長在 `src/modules/` 內；舊 code 不整修、不擴建。
  呼叫端逐一改指向新進入點。
- 呼叫端歸零的舊 code 當片內刪除；歸不了零 → 列 BOARD.md 新 `[ ]` 行。
  就地擴建舊 code 一律禁止。
- 大爆炸重寫一律禁止；一片只遷一個畫面的份量。

## 4. Subagent 回報格式

結論＋檔路徑:行號＋跳過了什麼。複述整份檔案內容一律禁止（code-rules 六）。
