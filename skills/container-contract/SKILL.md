# 集裝箱憲章 skill

憲章本體：本 plugin 的 `rules/container-contract.md`（本 SKILL.md 上兩層的 rules 目錄）。
畫面契約：同目錄 `rules/screen-contract.md`。

## 一、開場（不得跳過）

1. 讀憲章本體全文。
2. 本次任務涉及新模組 → 照憲章一收齊邊界定案四行，缺一不得開工。
3. 只改模組內部、不碰進入點與依賴 → 說明後照常進行，憲章三、五、八仍適用。

## 二、派 agent

派實作或驗證 subagent 時，把憲章本體原文附進 prompt，不得摘要、不得重寫。

## 三、交件前

照憲章二～六、八逐條核對，一條一行寫「過／不過＋證據位置」。
驗證由非實作者執行。
